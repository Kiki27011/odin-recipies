# Odin Recipes

This is a simple static website built with HTML and CSS that displays a collection of three recipes:
- Lasagna
- Pizza
- Chicken Alfredo

Each recipe is on its own page, accessible from a central homepage.

## Project Overview

The main page lists all the recipes, and each link leads to a detailed recipe page that includes:
- A heading and image of the dish
- A description of the recipe
- A list of ingredients
- Step-by-step preparation instructions

## Technologies Used

- **HTML** – for structure and content
- **CSS** – for basic styling and layout

## Features

- Clear, readable recipe content
- Consistent layout across pages
- Simple and minimal design

## Limitations

- Not responsive or mobile-optimized
- Lacks semantic HTML structure
- No interactivity (JavaScript not used)
- No advanced styling
